# Объединение и сжатие

## Объединение

Очередь задаёт порядок страниц или документов. Мультифора объединяет только однотипные наборы:

- PDF можно объединить только с PDF;
- DOCX можно объединить только с DOCX.

Перед запуском выберите путь итогового файла. Проверьте порядок очереди и откройте результат после создания.

## Сжатие изображений

Выберите уровень от максимального сжатия до максимального качества и место сохранения: рядом с источником, отдельная папка или замена исходника. Файл остаётся только если получившаяся версия действительно меньше оригинала.

## Сжатие PDF

Выберите автоматический, максимальный, качественный или оптимизационный профиль. В поставляемой сборке используется Ghostscript; при необходимости приложение может применить доступный резервный механизм PyMuPDF. Некоторые PDF уже оптимизированы и не станут меньше. Всегда сравнивайте качество и размер результата.
