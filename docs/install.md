# Установка и обновление

## Установщик

1. Откройте [последний выпуск](https://github.com/VseMirka200/multifora/releases/latest).
2. Скачайте `Multifora-Setup-<версия>.exe`.
3. Запустите файл и завершите установку.
4. Откройте Мультифору через меню «Пуск» или созданный ярлык.

Установщик — рекомендуемый вариант. В составе выпуска есть всё необходимое для основной работы, включая Ghostscript для сжатия PDF.

## Portable-версия

Скачайте ZIP-архив выпуска, распакуйте **всё** его содержимое в отдельную папку и запустите `Multifora.exe`. Не запускайте EXE прямо из архива: рядом с ним находятся необходимые файлы.

## Проверка загрузки

В выпуске есть файлы `.sha256`. В PowerShell выполните:

```powershell
Get-FileHash .\Multifora-Setup-<версия>.exe -Algorithm SHA256
```

Сравните полученный хеш с содержимым одноимённого файла `.sha256`.

## Обновление

Мультифора проверяет наличие новой версии через GitHub. Для обновления скачайте новый установщик и установите его поверх текущей версии; portable-версию обновляйте распаковкой нового архива в новую папку. Перед обновлением завершите операции с файлами.

!!! note "Зависимости документов"
    Для части конвертаций документов, где важно сохранить сложное оформление, нужен установленный и активированный Microsoft Word. Это не требуется для большинства операций с изображениями.
