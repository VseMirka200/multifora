# Объединение, сжатие и метаданные

[К оглавлению](README.md)

## Объединение

Можно объединять только файлы одного поддерживаемого формата:

- PDF с PDF — результат PDF;
- DOCX с DOCX — результат DOCX.

Формат определяется автоматически. Смешанный набор или менее двух файлов блокирует запуск. Результат формируется в порядке строк списка.

## Сжатие PDF

Доступны методы «Авто», «Максимальное сжатие», «Сохранить качество» и «Только оптимизация». Можно создать новый файл или заменить исходный. Для полноценного сжатия используется Ghostscript.

## Сжатие изображений

Доступны уровни качества 40%, 65%, 85% и 95%. Результаты можно записать вместо исходников, рядом с ними или в отдельную папку.

## Удаление метаданных

Операция предназначена для PDF, DOC, DOCX и ODT. Можно удалить выбранные поля или все поддерживаемые метаданные. Без выделения обрабатываются все подходящие документы в очереди.

Операции замены и удаления метаданных изменяют файлы. Для важных данных используйте резервную копию.

## Отмена

Кнопка «Отмена» отправляет запрос фоновому обработчику. Внешняя программа может завершать текущий шаг не мгновенно.
