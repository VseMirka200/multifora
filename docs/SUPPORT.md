# Поддержка

## Где искать ответ

1. Проверьте описание и инструкции в [README](../README.md).
2. Поищите похожее обращение в [Issues](https://github.com/VseMirka200/multifora/issues).

## Сообщение об ошибке

Если готового решения нет, создайте обращение по шаблону. Укажите:

- версию Мультифоры и Windows;
- способ установки: установщик, ZIP или исходный код;
- точные шаги воспроизведения;
- ожидаемый и фактический результат;
- форматы и примерное количество файлов;
- очищенный журнал и снимки экрана, если они полезны.

Не прикладывайте документы, личные пути, токены, пароли и другие конфиденциальные данные.

## Вопросы и предложения

Для предложения новой функции используйте шаблон Feature Request. Общие вопросы можно задавать в Issues, если в репозитории не включены GitHub Discussions.

## Уязвимости

Не создавайте публичное обращение. Используйте инструкции из [SECURITY.md](SECURITY.md).

Проект поддерживается сообществом без гарантированного времени ответа.
