# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии Мультифоры. Старые релизы и промежуточные сборки могут не получать исправлений.

| Версия | Поддержка |
| --- | --- |
| Последний релиз | Да |
| Старые релизы | Нет |

## Как сообщить об уязвимости

Не публикуйте сведения об уязвимости в открытом доступе.

Используйте [приватное сообщение об уязвимости GitHub](https://github.com/VseMirka200/multifora/security/advisories/new). Укажите:

- затронутую версию;
- тип и возможные последствия проблемы;
- минимальные шаги воспроизведения или подтверждающий пример;
- известный способ устранения, если он есть.

Удалите из журналов и вложений личные пути, документы, токены и другие конфиденциальные данные.

Если приватные отчёты GitHub недоступны, свяжитесь с сопровождающим через его [профиль GitHub](https://github.com/VseMirka200) и запросите закрытый канал до передачи технических подробностей.

Проект стремится подтвердить получение сообщения в течение семи дней. Пожалуйста, не раскрывайте подробности публично до выпуска исправления или согласованной даты раскрытия.

## Область действия

Политика охватывает код Мультифоры, официальный установщик, переносную сборку и процесс обновления. Проблемы сторонних библиотек следует также сообщать их разработчикам, если уязвимость не вызвана способом их использования в проекте.
