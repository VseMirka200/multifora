Установка и обновление

Установка готовой версии

  1. Откройте последний выпуск на GitHub.
  2. Скачайте Multifora-Setup-<версия>.exe.
  3. Запустите установщик и следуйте его шагам.
  4. После установки откройте Мультифору через меню «Пуск».

Для переносной версии скачайте ZIP-архив, распакуйте весь архив в постоянную папку и запускайте Multifora.exe из неё. Не запускайте программу прямо из архива.

Проверка скачанного файла

У каждого релиза есть файл контрольной суммы .sha256. В PowerShell выполните:

```powershell

Get-FileHash .\Multifora-Setup-<версия>.exe -Algorithm SHA256

```

Сравните получившийся хеш со значением в файле .sha256 из того же релиза. Скачивайте установщик и контрольную сумму только со страницы релизов проекта.

Обновление

  • Перед обновлением дождитесь завершения обработки файлов.
  • Установите новую версию поверх существующей либо распакуйте новую переносную версию в отдельную папку.
  • После запуска откройте Справка → Проверить обновления, если хотите проверить версию вручную.

Запуск из исходного кода

Для запуска из репозитория нужен Python 3.11 или новее. В корне проекта установите зависимости из requirements.txt, затем запустите multifora_start.py.

Далее: обзор руководства или полное руководство пользователя.
