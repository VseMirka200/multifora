Руководство по Мультифоре

Здесь собраны страницы для повседневной работы с файлами в Мультифоре. Начните с установки, затем откройте полное руководство или сразу перейдите к нужной операции.

Быстрый маршрут

  1. Установите программу.
  2. Прочитайте полное руководство, чтобы разобраться с очередью файлов и безопасной работой.
  3. Выберите нужную операцию.
