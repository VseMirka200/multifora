Конвертация и форматы

Конвертация преобразует документы и изображения в другой формат. Сначала добавьте подходящие файлы, затем на вкладке КОНВЕРТАЦИЯ выберите тип, исходный и целевой формат.

Порядок действий

  1. Добавьте в очередь файлы одного типа или отметьте нужные файлы галочками в колонке «В работу». Без отметок обрабатываются все подходящие файлы текущего списка.
  2. Выберите тип файла.
  3. Выберите формат «Конвертировать из».
  4. Выберите формат «Конвертировать в».
  5. Задайте способ сохранения и при необходимости папку результата.
  6. Нажмите «Конвертировать».

Куда сохраняются результаты

Колонка «Тип: сейчас → после» показывает исходный и выбранный целевой формат, например DOCX → PDF. Если файл не участвует в преобразовании или целевой формат ещё не выбран, после стрелки отображается прочерк.

Режим Результат
Спрашивать каждый раз Папка выбирается перед обработкой.
Рядом с исходными файлами Результат лежит возле каждого источника.
В папку «Конвертированные» Создаётся подпапка рядом с источником.
В отдельную папку Все результаты сохраняются в выбранное место.

Поддерживаемые категории

Тип Примеры исходных форматов Примеры целевых форматов
Документы DOCX, PDF, ODT, RTF, TXT, HTML, MD, EPUB, FB2, XPS, MOBI DOCX, PDF, ODT, RTF, TXT, HTML, MD; для PDF также JPG, JPEG, PNG, WEBP, TIFF, BMP
Изображения JPG, PNG, WEBP, BMP, TIFF, GIF, ICO, AVIF, HEIC, HEIF, QOI, SVG, PSD JPG, PNG, WEBP, BMP, TIFF, GIF, ICO, AVIF, HEIC, HEIF, QOI, PDF, SVG

Список в программе показывает только совместимые варианты для выбранного исходного формата. Конвертация в тот же формат не предлагается.

Чтобы сохранить страницы PDF как изображения, выберите тип «Документы», исходный формат PDF и один из доступных форматов изображения. У многостраничного PDF каждая страница сохраняется отдельно, с номером страницы в имени.

Проверяйте сложные документы Конвертация выполняется средствами приложения. При текстовом преобразовании могут теряться изображения, стили и таблицы. Старый формат DOC не поддерживается.
