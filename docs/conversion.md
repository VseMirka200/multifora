# Конвертация и форматы

Выберите тип файлов, исходный и целевой формат. Для смешанной очереди используйте вариант «Любой поддерживаемый…», если нужен общий целевой формат.

## Поддержка

| Тип | Источники | Результаты |
| --- | --- | --- |
| Документы | DOC, DOCX, PDF, ODT, RTF, TXT, HTML/HTM, MD/Markdown, EPUB, FB2, XPS/OXPS, MOBI | DOC, DOCX, PDF, ODT, RTF, TXT, HTML, MD |
| Изображения | JPG/JPE/JPEG/JFIF, PNG, WEBP, BMP/DIB, TIFF, GIF, ICO, TGA, PCX, JP2, QOI, DDS, EPS, ICNS, XBM, SGI/RGB/RGBA/BW, PPM/PGM/PBM, AVIF, HEIC/HEIF, SVG, PSD | JPG/JPEG, PNG, WEBP, BMP, TIFF, GIF, ICO, TGA, PCX, JP2, QOI, DDS, EPS, ICNS, XBM, SGI, PPM/PGM/PBM, AVIF, HEIC/HEIF, PDF, SVG |

Формат не предлагается как цель для самого себя. Возможности конкретного преобразования зависят от установленной библиотеки и структуры файла.

## Сохранение

Выберите один из режимов: рядом с источником, в подпапку `Конвертированные` или в выбранную общую папку. Откройте несколько готовых файлов после конвертации, особенно если документ содержит таблицы, шрифты или сложную разметку.

## Microsoft Word

DOC/DOCX/ODT/RTF/HTML-конвертации, в которых требуется верность оформлению, могут использовать Microsoft Word. Установите и активируйте Word, если приложение сообщает о недоступности этой возможности.
