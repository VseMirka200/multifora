# Конвертация

[К оглавлению](README.md)

## Порядок работы

1. Добавьте документы или изображения.
2. Выберите категорию, исходный и целевой форматы.
3. Выберите способ сохранения.
4. Запустите конвертацию и подтвердите действие.

Смешанный режим позволяет преобразовать несколько поддерживаемых исходных расширений одной категории в общий целевой формат.

## Документы

Входные форматы:

`DOC`, `DOCX`, `PDF`, `ODT`, `RTF`, `TXT`, `HTML`, `MD`, `EPUB`, `FB2`, `XPS`, `MOBI`.

Целевые форматы:

`DOC`, `DOCX`, `PDF`, `ODT`, `RTF`, `TXT`, `HTML`, `MD`.

Не каждая пара преобразований полностью сохраняет сложное оформление. Для DOC требуется Microsoft Word. Для DOCX → PDF приложение предпочитает Word, если он установлен.

## Изображения

Поддерживаются `JPG`, `JPEG`, `PNG`, `WEBP`, `BMP`, `TIFF`, `GIF`, `ICO`, `TGA`, `PCX`, `JP2`, `QOI`, `DDS`, `EPS`, `ICNS`, `XBM`, `SGI`, `PPM`, `PGM`, `PBM`, `AVIF`, `HEIC`, `HEIF`, `SVG` и `PSD`.

В число целевых форматов входит PDF, но не входит PSD. Доступность редких форматов зависит от библиотек и кодеков. Анимация, слои, векторные данные и прозрачность могут быть упрощены.
