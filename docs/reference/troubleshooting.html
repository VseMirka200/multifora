Устранение неполадок

Операция не запускается

Проверьте следующее:

  1. В очереди есть файлы, подходящие для выбранной операции.
  2. Отмеченные в колонке «В работу» файлы не скрыты поиском или фильтрами. Чтобы снова обрабатывать все подходящие файлы, снимите отметки, предварительно показав скрытые строки.
  3. Выбран целевой формат, папка или итоговый файл, если это требуется.
  4. На диске достаточно свободного места.
  5. Исходный файл не открыт в другой программе и доступен для чтения.
  6. У вас есть права на запись в папку результата.

Формат недоступен для конвертации

Выберите правильный тип и исходный формат на вкладке КОНВЕРТАЦИЯ. Список назначения зависит от источника: не все форматы можно преобразовать друг в друга. Для части офисных преобразований установите и активируйте Microsoft Word.

Не удаётся объединить документы

Объединение работает только для PDF с PDF или DOCX с DOCX. Удалите из очереди файлы другого типа, расположите оставшиеся документы в нужном порядке и заново укажите итоговый файл.

PDF или изображение почти не уменьшилось

Некоторые файлы уже оптимизированы. Попробуйте другой профиль сжатия на копии файла, но обязательно сравните качество. Не заменяйте оригинал, пока результат не проверен.

Не работает контекстное меню Windows

Выключите и снова включите «Добавить в контекстное меню Windows» в настройках. Затем закройте и откройте Проводник. Если проблема сохраняется, перезапустите Мультифору и убедитесь, что настройка включена для текущего пользователя Windows.

Как подготовить обращение

В меню «Справка» скачайте журналы. Укажите версию Мультифоры, версию Windows, шаги воспроизведения, ожидаемый и фактический результат. Прикладывайте только обезличенный фрагмент журнала.

Не публикуйте личные документы, пароли, токены или полные локальные пути. Создать обращение можно через GitHub Issues. Для уязвимостей используйте приватный GitHub Security Advisory.
