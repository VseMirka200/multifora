# Работа со списком файлов

[К оглавлению](README.md)

## Добавление файлов

Файлы и папки можно добавить кнопками, перетаскиванием из Проводника, через команду «Добавить в Мультифору» или аргументы запуска.

При добавлении папки приложение предлагает добавить саму папку либо всё её содержимое. При выборе содержимого обходятся и вложенные папки. Повторно добавленный путь не создаёт дубликат.

## Выделение и порядок

- Щелчок выбирает одну строку.
- `Ctrl` позволяет выбирать отдельные строки.
- `Shift` выбирает диапазон.
- `Ctrl+A` выбирает все видимые строки.
- Если ничего не выделено, некоторые операции применяются ко всем подходящим файлам.
- Порядок строк важен для нумерации и объединения.

Поиск и фильтры меняют только отображение: скрытые элементы остаются в общей очереди.

## Клавиатурные действия

| Действие | Клавиша |
|---|---|
| Открыть выделенные файлы | `Enter` |
| Скопировать файлы | `Ctrl+C` |
| Переименовать один файл | `F2` |
| Удалить строки из очереди | `Delete` |
| Выделить все строки | `Ctrl+A` |

`Delete` удаляет элементы только из списка Мультифоры. Файлы на диске не удаляются.

## Предварительный просмотр

Перед переименованием приложение проверяет недопустимые имена, повторяющиеся результаты, конфликты с существующими файлами и отсутствие фактических изменений.
