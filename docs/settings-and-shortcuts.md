# Настройки и горячие клавиши

[К оглавлению](README.md)

## Настройки

- системная, тёмная или светлая тема;
- автоматическая очистка списка;
- отключение отдельных предупреждающих окон;
- ярлыки на рабочем столе и в меню «Пуск»;
- команда «Добавить в Мультифору» в контекстном меню Windows;
- автоматическая проверка обновлений.

## Обновления

При обнаружении новой версии появляется кнопка «Скачать обновление». Приложение скачивает EXE-установщик из GitHub Releases и проверяет его контрольную сумму SHA-256. После успешной проверки появляется кнопка «Установить обновление».

При запуске установки Мультифора закрывается. Обычный установщик заменяет файлы предыдущей версии и затем предлагает запустить обновлённое приложение. Настройки и журналы в `%APPDATA%\Multifora` при обновлении не удаляются.

## Журнал

В журнале можно фильтровать уровни, искать текст и сохранять видимые строки. Данные приложения находятся в `%APPDATA%\Multifora`, журнал — в `%APPDATA%\Multifora\logs`.

## Горячие клавиши списка

| Клавиша | Действие |
|---|---|
| `Delete` | убрать выделенные элементы из очереди |
| `Enter` | открыть выделенные файлы |
| `Ctrl+C` | скопировать выделенные файлы |
| `F2` | переименовать один файл |
| `Ctrl+A` | выделить все строки |

## Окна подтверждения

| Клавиша | Ответ |
|---|---|
| `Enter` или цифровой `Enter` | «Да» |
| `Delete` | «Нет» |
| `Esc` или закрытие окна | «Нет» |

## Контекстное меню Windows

После включения настройки Проводник показывает пункт «Добавить в Мультифору». Если приложение уже открыто, пути передаются в существующее окно. После обновления приложения перезапустите его, чтобы регистрация меню проверилась автоматически.
