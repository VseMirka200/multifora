# Установка и первый запуск

[К оглавлению](README.md)

## Готовая версия

1. Откройте [последний выпуск](https://github.com/VseMirka200/multifora/releases/latest).
2. Скачайте `Multifora-Setup-<версия>.exe`.
3. Запустите установщик и завершите установку.
4. Откройте Мультифору через меню «Пуск» или ярлык.

ZIP-архив предназначен для переносного запуска без установки: распакуйте его в отдельную папку и запустите `Multifora.exe`.

Если Windows показывает предупреждение SmartScreen, убедитесь, что файл загружен из официального репозитория проекта, и только после этого разрешайте запуск.

## Запуск из исходного кода

Требования:

- Windows 10 или новее;
- Python 3.11 или новее;
- доступ к интернету при первой установке зависимостей.

Порядок запуска:

1. Скачайте или клонируйте репозиторий.
2. Запустите `start_multifora.bat` из корня проекта.
3. Скрипт создаст `.venv`, установит зависимости из `requirements.txt` и откроет приложение.

Ручной запуск:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe multifora_start.py
```

## Дополнительные компоненты

- Microsoft Word нужен для некоторых операций с DOC и для наиболее точной конвертации документов Word в PDF.
- Ghostscript используется для сжатия PDF. Приложение ищет его в своей папке, системном реестре и стандартных каталогах установки.
- Встроенные библиотеки выполняют большинство операций с PDF, DOCX, ODT и изображениями.

## Первоначальная настройка

В разделе «Настройки» можно выбрать тему, настроить очистку очереди, создать ярлыки, добавить команду в контекстное меню Windows и включить проверку обновлений.

## Обновление установленной версии

1. Откройте «Настройки» → «Обновления» и нажмите «Проверить обновления».
2. Если доступна новая версия, нажмите «Скачать обновление».
3. После проверки контрольной суммы нажмите «Установить обновление».
4. Мультифора закроется и откроет обычный установщик. Он заменит файлы старой версии, сохранив пользовательские настройки.

Автоматическое обновление доступно только для релизов, содержащих EXE-установщик и файл SHA-256. Для переносной ZIP-версии также можно скачать установщик, но он установит приложение в обычную пользовательскую папку Windows.
