# Замена движков в Мультифоре

Объём переноса включает операции, доступные сейчас в Мультифоре. Python
управляет преобразованиями и использует библиотеки с нативными компонентами.

Итоговый прогон с эталонным PDFCraft дал 369 пройденных тестов, 8 пропусков
и 249 пройденных вложенных проверок. Приложение Windows запустилось и
выполнило контрольные преобразования. Установщик успешно прошёл временную
установку и удаление, в установленном приложении оба старых CLI отсутствовали.

`pypdf` и PDFium выполняют объединение, сжатие, вывод страниц, экспорт в TXT
и DOCX. Проверены порядок страниц, закладки, кириллица, сканы, сжатие
встроенных изображений, ошибки и очистка при отмене. Сравнительная проверка
может использовать отдельную копию PDFCraft через
`MULTIFORA_REFERENCE_PDFCRAFT`. Основные проверки запускаются без неё.

Офисные преобразования охватывают входы DOCX, ODT, RTF, TXT и HTML, а также
выходы в те же форматы и PDF. PDF в ODT, RTF и HTML по-прежнему проходит через
промежуточный DOCX. Проверены все различные пары форматов, переход DOCX → ODT →
DOCX с таблицей и изображением, а также кириллица, размеры страниц и
колонтитулы при выводе DOCX в PDF. ReportLab и Qt выполняют вывод PDF. Qt
подбирает системные шрифты для текста, которому нужна сложная раскладка.

Сложная вёрстка зависит от формата. В PDF → DOCX текст становится редактируемым,
а страницы без текстового слоя переносятся как изображения. При преобразованиях
могут отличаться положение плавающих объектов, оформление сложных таблиц,
шрифты и параметры отдельных секций. Сжатие сохраняет исходный PDF, если
перекодирование подходящих растровых изображений увеличивает размер.
