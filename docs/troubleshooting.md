# Решение проблем

[К оглавлению](README.md)

## Файл не добавляется

- Проверьте существование и доступность пути.
- Снимите фильтры: файл мог добавиться, но быть скрыт.
- Убедитесь, что путь ещё не находится в очереди.
- После обновления перезапустите приложение для обновления контекстного меню.

## Кнопка операции недоступна

- Выделите подходящие файлы.
- Заполните обязательный путь результата.
- Для объединения выберите минимум два PDF либо два DOCX.
- Для сжатия не смешивайте PDF и изображения.
- Проверьте переименование на конфликты.

## Не работает DOC

Установите Microsoft Word: старый формат DOC не обрабатывается библиотекой python-docx напрямую.

## Не сжимается PDF

Установите Ghostscript в стандартный каталог либо используйте сборку с `bin\gswin64\gswin64c.exe`. После установки перезапустите приложение. Проверьте доступ к PDF на запись.

## Где находятся логи

```text
%APPDATA%\Multifora\logs\multifora_logs.txt
%APPDATA%\Multifora\debug_args.txt
```

Перед публикацией удалите из журнала личные пути и имена файлов.

## Сообщение об ошибке

Сначала проверьте [существующие обращения](https://github.com/VseMirka200/multifora/issues). Если похожей проблемы нет, [создайте новое обращение](https://github.com/VseMirka200/multifora/issues/new/choose) по шаблону ошибки. Укажите версию программы и Windows, шаги воспроизведения, ожидаемый и фактический результат, форматы файлов и очищенный журнал.
