## Быстрый старт

1. Добавьте файлы кнопкой, перетаскиванием или через контекстное меню Windows.
2. При необходимости выделите только те строки, которые нужно обработать.
3. Откройте вкладку нужной операции и задайте параметры.
4. Проверьте предварительный результат и запустите обработку.
5. В окне подтверждения нажмите `Enter` для ответа «Да» или `Delete` для ответа «Нет».

Перед операциями, заменяющими исходные файлы, рекомендуется иметь резервную копию.
