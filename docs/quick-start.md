# Первые шаги

1. Добавьте файлы кнопкой, перетаскиванием, из папки или через пункт «Добавить в Мультифору» в Проводнике.
2. Проверьте очередь. Используйте поиск, фильтр, сортировку и ручное перетаскивание строк, чтобы задать порядок.
3. Выберите вкладку: **Переименование**, **Конвертация**, **Объединение** или **Сжатие**.
4. Настройте параметры и прочитайте предварительный результат.
5. Запустите действие и откройте созданные файлы для проверки.

!!! warning "Не заменяйте оригиналы без копии"
    В отдельных режимах можно перезаписывать исходники. Сначала сделайте резервную копию и испытайте параметры на небольшой группе файлов.

## Где появляются результаты

- Конвертированные файлы обычно попадают в папку `Конвертированные` рядом с источником; можно выбрать размещение рядом или общую папку.
- Сжатые изображения по умолчанию создаются рядом с суффиксом `_compressed`; для изображений доступна и замена оригинала.
- Сжатые PDF создаются рядом с оригиналом, если не включена его замена.
- Объединённый документ сохраняется в путь, выбранный перед запуском.

Далее: [переименование](rename.md), [конвертация](conversion.md) или [устранение проблем](troubleshooting.md).
