# Выпуск Windows-версии

1. Обновите `APP_VERSION` в `app/core/app_identity.py` до версии без префикса `v`.
2. Запустите тесты и проверьте изменения перед выпуском.
3. Создайте и отправьте тег `v<версия>`.
4. Workflow [Release](../../.github/workflows/release.yml) соберёт установщик, portable ZIP, контрольные суммы и создаст GitHub Release.
5. Скачайте опубликованные файлы, проверьте SHA-256 и запуск обоих вариантов.

В релиз входят `Multifora-Setup-<версия>.exe` и его `.sha256`, portable ZIP и его `.sha256`, а также `CHANGELOG.md`. Не изменяйте артефакты после проверки.
