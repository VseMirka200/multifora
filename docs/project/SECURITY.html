Политика безопасности

Исправления безопасности выпускаются для последней опубликованной версии Мультифоры. Старые выпуски могут не получать обновления.

Версия Поддержка
Последний выпуск Да
Старые выпуски Нет

Сообщить об уязвимости

Не публикуйте детали уязвимости в открытом issue. Используйте приватный GitHub Security Advisory, указав затронутую версию, последствия, минимальные шаги воспроизведения и возможное исправление.

Удалите из логов и вложений личные пути, документы, токены и другие конфиденциальные данные. Если Advisory недоступен, свяжитесь с сопровождающим, не раскрывая подробности публично. Проект старается подтвердить получение сообщения в течение семи дней.

Политика охватывает исходный код, официальный установщик, portable-сборку и процесс обновления.
