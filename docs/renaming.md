# Переименование и шаблоны

[К оглавлению](README.md)

## Порядок работы

1. Добавьте файлы и при необходимости измените порядок.
2. Откройте вкладку «Переименование».
3. Выберите готовый или пользовательский шаблон.
4. Настройте параметры и проверьте новые имена.
5. Нажмите «Начать действие» и подтвердите операцию.

История переименований позволяет отменять и повторять сохранённые операции.

## Доступные преобразования

- добавление текста в начало или конец;
- удаление символов или заданного текста;
- обычная замена и регулярные выражения;
- изменение регистра;
- нумерация, префиксы и даты;
- пользовательские шаблоны.

## Токены

| Токен | Значение |
|---|---|
| `{name}` | исходное имя без расширения |
| `{ext}` | расширение без точки |
| `{date}` | дата из параметров шаблона |
| `{created}` | дата создания файла |
| `{modified}` | дата изменения файла |
| `{file_date}` | дата изменения файла |
| `{exif_date}` | дата съёмки из EXIF |
| `{width}` | ширина изображения |
| `{height}` | высота изображения |
| `{num}` | порядковый номер |

Пример:

```text
{exif_date}_{num:04d,start=1,step=1}_{name}
```

Параметры `start`, `step` и `digits` задают первый номер, шаг и количество цифр. Если метаданные отсутствуют, соответствующий токен заменяется пустой строкой.

Перед обработкой приложение блокирует недопустимые имена и предупреждает о конфликтах. Для важных данных сначала проверьте шаблон на копиях файлов.
