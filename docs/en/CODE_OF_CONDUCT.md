# Code of conduct

Treat every participant respectfully and discuss technical work constructively. Harassment, discrimination, threats, trolling, and publishing private information are not acceptable. Maintainers may remove content or restrict participation. Report concerns privately to the [maintainer](https://github.com/VseMirka200); do not expose sensitive details publicly.

Based on the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
