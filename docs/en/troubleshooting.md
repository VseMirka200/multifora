# Troubleshooting

If an action button is disabled, add an appropriate file and complete the required format or output-path fields. Merge also requires a destination filename.

If a document conversion fails, make sure the file is supported, not open elsewhere, and that free disk space is available. Install Microsoft Word for relevant Office conversions. Open logs from **Справка** and include a redacted extract in an [issue](https://github.com/VseMirka200/multifora/issues/new/choose).

An already optimized PDF may not get smaller. Try another profile on a copy. Do not attach personal documents, tokens, or full local paths to public issues.
