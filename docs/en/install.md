# Install and update

Download `Multifora-Setup-<version>.exe` from the [latest release](https://github.com/VseMirka200/multifora/releases/latest), run it, then start Multifora from the Start menu. For a portable install, extract the whole ZIP to a permanent folder before starting `Multifora.exe`.

Use `Get-FileHash <file> -Algorithm SHA256` in PowerShell to compare a download with its accompanying `.sha256` file. Install a newer installer over the existing version, or extract a new portable archive to a new folder. Finish active file operations first.

Multifora targets 64-bit Windows. Running the source code requires Python 3.11+. Some office-document conversions require an installed and activated Microsoft Word.
