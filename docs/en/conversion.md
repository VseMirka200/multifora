# Convert files and formats

Select a file type, source format, and target format. A mixed-source choice is available when several supported sources share one target.

| Type | Input | Output |
| --- | --- | --- |
| Documents | DOC, DOCX, PDF, ODT, RTF, TXT, HTML, MD, EPUB, FB2, XPS, MOBI | DOC, DOCX, PDF, ODT, RTF, TXT, HTML, MD |
| Images | JPG/JPEG, PNG, WEBP, BMP, TIFF, GIF, ICO, TGA, PCX, JP2, QOI, DDS, EPS, ICNS, XBM, SGI, PPM/PGM/PBM, AVIF, HEIC/HEIF, SVG, PSD | JPG/JPEG, PNG, WEBP, BMP, TIFF, GIF, ICO, TGA, PCX, JP2, QOI, DDS, EPS, ICNS, XBM, SGI, PPM/PGM/PBM, AVIF, HEIC/HEIF, PDF, SVG |

Save results next to sources, in a `Конвертированные` folder, or in a selected common folder. Office conversions that preserve complex layout may use Microsoft Word.
