# Batch rename

Use the **ПЕРЕИМЕНОВАНИЕ** tab to select a template. Multifora previews names and checks invalid characters, duplicate targets, and conflicts before it starts. Templates support filename text, numbering, dates, image dimensions, EXIF data, text replacement, and regular expressions.

Test a template on copies first. Custom templates can be exported to JSON and imported on another computer. Rename history is useful for review but is not a backup.
