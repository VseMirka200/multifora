# Merge and compress

The queue determines merge order. Multifora merges PDF with PDF only and DOCX with DOCX only; choose the output path before starting.

For images, select a compression level and save next to the source, to a separate folder, or replace the original. An output is retained only when it is smaller. PDF compression offers automatic, maximum, quality, and optimization profiles. The packaged build includes Ghostscript and can use PyMuPDF as a fallback. Check visual quality before replacing a PDF.
