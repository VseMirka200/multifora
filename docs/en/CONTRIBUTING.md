# Contributing

Contributions of bug fixes, tests, interface improvements, documentation, and agreed features are welcome. Follow the [code of conduct](CODE_OF_CONDUCT.md), report vulnerabilities privately, and keep each PR focused.

Use Windows and Python 3.11+, install `requirements.txt`, add tests for changed behavior, and run the test suite plus `ruff check .`. Do not commit virtual environments, builds, caches, logs, or personal files. The project is licensed under MIT.
