# Settings and Explorer menu

Settings include light, dark, and system themes; operation preferences; templates; and Windows integration. Enable **Добавить в контекстное меню Windows** to add **Добавить в Мультифору** to Explorer for files and folders. It only adds items to the queue; it never runs an operation automatically.

The registration is per-user and normally needs no administrator privileges. If it does not appear, restart Explorer or toggle the option off and on.
