Quick start

  1. Add files or a folder by dragging them in, using the add button, or choosing Добавить в Мультифору in Explorer.
  2. Review the queue; search, filter, sort, or drag rows to set the order.
  3. Select ПЕРЕИМЕНОВАНИЕ (rename), КОНВЕРТАЦИЯ (convert), ОБЪЕДИНЕНИЕ (merge), or СЖАТИЕ (compress).
  4. Configure the operation and inspect the preview.
  5. Run it and open a result before deleting originals.

Back up files before using a replace-original option.
