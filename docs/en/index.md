<section class="mf-section mf-section--faq" id="faq">
  <div class="mf-section__heading"><span class="mf-section__eyebrow">QUESTIONS</span><h2>Good to know</h2></div>
  <div class="mf-faq">
    <details><summary>Do I need to upload files here?</summary><p>No. This is an application website and documentation, not an online converter. Work files are processed locally in the Windows desktop app.</p></details>
    <details><summary>Can I overwrite the original files?</summary><p>Some operations support replacing originals. Review the preview and create backups before doing so.</p></details>
    <details><summary>What if a format is unavailable?</summary><p>Check the <a href="conversion/">supported formats guide</a>. Some conversions depend on extra software, such as Microsoft Word.</p></details>
  </div>
