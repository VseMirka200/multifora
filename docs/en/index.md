# Multifora

**Batch file processing for Windows — without uploading work files to a cloud service.**

Rename collections, convert documents and images, merge PDF/DOCX files, and reduce file size in one desktop application.

## One queue, several jobs

Rename files with templates, convert supported documents and images, merge same-type PDF or DOCX sets, and compress PDF or images locally. Add items by drag and drop, dialogs, launch arguments, or the Windows Explorer menu.

## Downloads and privacy

Download the installer or portable ZIP from [the latest release](https://github.com/VseMirka200/multifora/releases/latest). Release assets include SHA-256 checksums. This documentation site has no analytics, cookies, or contact form.

The application interface is currently Russian. The English guide explains the same controls and workflows.
