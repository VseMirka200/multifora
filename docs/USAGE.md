# Руководство пользователя

[Установка](../README.md#установка) · [Устранение неполадок](SUPPORT.md#частые-вопросы-и-быстрые-проверки)

При переходе на вкладку операции над очередью появляются её команды. Двойной щелчок по вкладке сворачивает и разворачивает ленту.

## Очередь файлов

Перетащите файлы или папки в окно. В пустой очереди доступны кнопки **«Добавить файлы»** и **«Добавить папки»**. Сочетания клавиш для добавления работают и при заполненной очереди. Для папки можно добавить саму папку для переименования или собрать файлы из неё и всех вложенных папок. После добавления программа показывает число новых элементов, дубликатов, неподдерживаемых и недоступных файлов.

- Флажки **«В работу»** определяют состав пакета. Без флажков обрабатываются все подходящие файлы, видимые в текущей вкладке с учётом поиска и фильтров.
- Поиск по имени и фильтры по типу и расширению меняют видимую часть очереди. Отметки скрытых файлов сохраняются. Если отмечены только скрытые файлы, покажите их с помощью **«Сбросить фильтры»** или перейдите на другую вкладку.
- Выделение строк мышью или клавиатурой используется для команд таблицы. Проверьте сводку **«В работу»** перед запуском пакетной операции.

| Клавиши | Действие |
| --- | --- |
| `Ctrl+O`, `Ctrl+Shift+O` | Добавить файлы или папку соответственно. |
| `Ctrl+F` | Перейти к поиску. |
| `Пробел`, `Ctrl+A` | Изменить отметку текущей строки или отметить все видимые строки соответственно. |
| `Enter`, `F2`, `Ctrl+C` | Открыть, переименовать или скопировать выбранные элементы. Команда `F2` работает с одним элементом. |
| `Delete` | Открыть подтверждение удаления из очереди. Перемещение файлов в корзину включается отдельным флажком в диалоге. |
| `Alt+↑`, `Alt+↓` | Переместить текущий документ на вкладке «Объединение». |

## Переименование

Выберите правило и нажмите **«Параметры»**, чтобы настроить его. Кнопка **«Переименовать»** находится справа под очередью. Таблица покажет исходные и будущие имена. Если имя занято, проверьте предложенное свободное имя. Для недопустимого имени исправьте шаблон и дождитесь обновления предпросмотра. Кнопка **«Показать первую проблему»** переводит фокус на соответствующую строку.

Перед запуском подтвердите изменение имён в исходных папках. Из меню **«Шаблоны и история» → «История»** можно откатить переименование текущей сессии. Для отката файлы должны быть доступны, а прежние имена — свободны. Пользовательские шаблоны можно сохранять, применять, импортировать и экспортировать.

## Конвертация

Выберите тип файлов, исходный и целевой форматы. Для совместимого смешанного набора используйте пункт **«Любой поддерживаемый документ»** или **«Любое поддерживаемое изображение»**. Сводка покажет количество файлов, которые соответствуют выбранным параметрам.

- Для документов доступность целей зависит от источника. В список входят DOCX, PDF, ODT, RTF, TXT и HTML. Для PDF также доступны поддерживаемые форматы изображений. Старый DOC отсутствует в списке конвертации.
- Для изображений список источников и целей различается. Используйте форматы, доступные в текущем списке приложения.
- Результат можно сохранить рядом с исходниками, в подпапках **«Конвертированные»** или в выбранной общей папке. В режиме **«Спрашивать каждый раз»** место сохранения выбирается при запуске.

## Объединение

Добавьте как минимум два PDF или два DOCX одного формата. Документы объединяются сверху вниз. Чтобы изменить порядок, перетащите строку или используйте `Alt+↑` и `Alt+↓`. Нажмите **«Объединить»**, укажите имя и папку результата, затем подтвердите запуск.

## Сжатие

Выберите PDF или изображения и задайте метод или качество. Столбец **«Размер → оценка»** показывает примерный результат. После завершения в сводке и подробностях указаны фактические размеры. Уже оптимизированный файл может остаться без изменения.

Можно создать отдельные файлы или заменить исходники. При замене программа запрашивает явное подтверждение. Чтобы оценить качество, сначала сожмите копию.

## Результаты и отмена

Сводка под очередью показывает результат операции, количество новых и изменённых файлов, ошибки и предупреждения. Кнопки **«Открыть»** и **«Папка результата»** ведут к готовым файлам.

В **«Подробностях»** можно выбрать проблемную строку, открыть технические сведения и скопировать их. Кнопка повтора появляется для ошибок, допускающих повторную попытку. Повтор использует прежние параметры и применяется к указанным файлам.

При отмене очередь сохраняется, а уже опубликованные результаты остаются доступны. Автоочистка после успешной операции убирает элементы из очереди, сохраняя файлы на диске.

## Настройки и справка

Откройте **«Настройки»**. Там можно выбрать тему, включить проверку обновлений, настроить автоочистку очереди, создать ярлыки и управлять пунктом контекстного меню Проводника.

На вкладке **«Справка»** доступны сведения о версии, ручная проверка обновлений, сохранение журнала и ссылка для сообщения об ошибке. Перед отправкой журнала просмотрите его содержимое. [Поддержка и устранение неполадок](SUPPORT.md).
