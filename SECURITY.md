# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней версии Мультифоры. Старые релизы и промежуточные сборки для разработки могут не получать обновления безопасности.

| Версия | Поддерживается |
| --- | --- |
| Последний релиз | Да |
| Старые релизы | Нет |

## Сообщение об уязвимости

Не публикуйте сведения о предполагаемой уязвимости в открытой задаче, обсуждении или запросе на слияние.

Используйте страницу GitHub для конфиденциального сообщения об уязвимости:

https://github.com/VseMirka200/multifora/security/advisories/new

Укажите затронутую версию, тип и возможные последствия проблемы, действия для воспроизведения или подтверждающий пример, а также предлагаемый способ устранения, если он известен. Перед прикреплением файлов и журналов удалите из них посторонние личные данные.

Если конфиденциальные сообщения об уязвимостях недоступны, свяжитесь с сопровождающим проекта по контактным данным из его [профиля GitHub](https://github.com/VseMirka200) и запросите закрытый канал связи до передачи технических подробностей.

Проект стремится подтвердить получение сообщения в течение семи дней. По мере расследования и устранения проблемы автор сообщения будет получать обновления. Пожалуйста, дождитесь выпуска исправления перед публичным раскрытием подробностей.
