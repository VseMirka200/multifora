# Поддержка

Поддержите Мультифору без денежных переводов: [подключитесь к разработке](CONTRIBUTING.md), предложите улучшение или сообщите об ошибке.

Для вопросов по работе приложения сначала используйте [руководство](https://vsemirka200.github.io/multifora/) и [раздел устранения неполадок](https://vsemirka200.github.io/multifora/reference/troubleshooting.html).

- О сбое или неверном результате сообщайте через [шаблоны GitHub Issues](https://github.com/VseMirka200/multifora/issues/new/choose).
- Для предложения новой функции создайте issue с описанием задачи и примером желаемого результата.
- Уязвимости отправляйте только по [закрытому каналу безопасности](SECURITY.md).

В обращении укажите версию Мультифоры из «Справка → О программе», версию Windows и способ запуска: установщик, переносная сборка или исходники. Опишите выполненные действия, ожидаемый и фактический результат. Для проблем с обработкой укажите формат файлов, состояние отметок «В работу», фильтры и способ сохранения результата.

Журнал можно сохранить через «Справка → Скачать логи». Перед публикацией удалите конфиденциальные документы, токены, пароли и личные пути к файлам. Для воспроизведения используйте обезличенные примеры.

Номер версии в исходном коде может быть новее [последнего опубликованного релиза](https://github.com/VseMirka200/multifora/releases/latest). Для проверки исправления уточняйте, используется ли готовая сборка или изменённые исходники.
