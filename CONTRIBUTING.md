# Участие в разработке Мультифоры

Спасибо за желание помочь проекту. Мы приветствуем сообщения об ошибках, улучшения документации и интерфейса, а также небольшие целевые изменения кода.

## Перед началом работы

Перед созданием новой задачи проверьте [трекер задач](https://github.com/VseMirka200/multifora/issues). В сообщении об ошибке укажите версию Мультифоры и Windows, последовательность действий для воспроизведения, ожидаемый и фактический результат. Приложите журнал работы или небольшой пример файла, если они помогут воспроизвести проблему. Предварительно удалите из них личные и конфиденциальные данные.

Перед реализацией крупной функции или существенным изменением поведения создайте задачу, чтобы заранее обсудить ожидаемый результат и объём работы.

Не публикуйте сведения об уязвимостях в открытых задачах. Следуйте инструкции из [SECURITY.md](SECURITY.md).

## Настройка среды разработки

Мультифора разрабатывается для Windows и требует Python 3.11 или новее.

```powershell
git clone https://github.com/VseMirka200/multifora.git
cd multifora
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запустите приложение командой:

```powershell
.\.venv\Scripts\python.exe multifora_start.py
```

Для некоторых операций с документами требуется Microsoft Word, а для сжатия PDF — Ghostscript. Изменения, не связанные с этими функциями, можно разрабатывать и проверять без них.

## Внесение изменений

1. Создайте форк репозитория и отдельную ветку от `main`.
2. Ограничьте изменение одной понятной задачей.
3. Следуйте существующим шаблонам Python и PyQt в соседнем коде.
4. Добавляйте или обновляйте тесты при изменении поведения и исправлении ошибок.
5. Обновляйте пользовательскую документацию при изменении установки, поведения или поддерживаемых форматов.
6. Запустите связанные тесты, а затем весь набор тестов.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```
