# Multifora Craft — исходный проект Windows x64

Полный проект на основе предоставленного архива CLI-интеграции Multifora (не текущей ветки main репозитория). Содержит интерфейс, Python-мост, маршруты конвертации, рабочие потоки, манифест шести официальных ArtCraft portable-пакетов, загрузчик, тесты и конфигурацию сборки.

## Облачная сборка

В отдельной ветке `craft-portable` репозитория разместите содержимое этого архива **вместо** старого дерева проекта, не смешивая старые и новые движки. Не удаляйте `.git` при локальной замене. Workflow `.github/workflows/craft-portable.yml` запускается при push в эту ветку; ручной запуск также предусмотрен (workflow_dispatch доступен после размещения workflow в основной ветке). В Actions откройте успешный запуск Multifora Craft Portable Win64 и скачайте артефакт с ZIP и SHA-256. Никаких инструментов сборки на компьютере пользователя не нужно. Сборка использует закреплённые версии Python-пакетов из исходного проекта; их доступность на runner не проверена.

## Локальный запуск исходников

См. README-CLI.md. Для готовой сборки на Windows можно использовать scripts/build_app.bat --no-pause, затем python scripts/package_craft_portable.py. Необходимы Python x64 и зависимости сборки; Rust, Git и Visual Studio для CLI-движков не нужны.

## Статус

В этом архиве нет EXE движков, Python runtime и собранного Multifora.exe. Они загружаются/создаются в процессе сборки. Исходники сторонних ArtCraft-репозиториев не дублируются: используются официальные release-пакеты с проверкой SHA-256. Windows-сборка и фактическое наличие CLI в скачанных пакетах пока не проверены. Если любой тест или проверка завершится ошибкой, workflow не публикует готовый архив. Ограничения форматов и лицензий описаны в README-CLI.md. Старые вспомогательные сценарии установщика и часть тестов сохранены из исходной версии, но не используются в данном portable workflow.
