# Мультифора

Мультифора — приложение для пакетного переименования, конвертации, объединения и сжатия файлов в Windows. Обработка выполняется локально встроенными движками Python, Qt и PDFium.

[Скачать последнюю версию](https://github.com/VseMirka200/multifora/releases/latest) · [Руководство пользователя](docs/USAGE.md) · [Поддержка](docs/SUPPORT.md)

## Установка

Откройте [страницу последнего релиза](https://github.com/VseMirka200/multifora/releases/latest) и скачайте подходящий файл.

- **Установщик.** Запустите `Multifora-Setup-<версия>.exe` и следуйте шагам установки.
- **Переносная версия.** Распакуйте `Multifora-Portable-<версия>.zip` целиком и запустите `Multifora.exe` из распакованной папки.
- **Тихая установка.** Если в выпуске есть соответствующий BAT-файл, поместите его рядом с одним установщиком и запустите.

Если выпуск содержит `SHA256SUMS.txt`, сверьте значение для скачанного файла. Пример команды PowerShell для установщика версии 1.0.5: `Get-FileHash -Algorithm SHA256 -LiteralPath ".\Multifora-Setup-1.0.5.exe"`.

## Быстрый старт

1. Перетащите файлы в окно или нажмите **«Добавить файлы»** в пустой очереди. Пункт **«Добавить в Мультифору»** для Проводника включается в настройках.
2. Выберите операцию и задайте параметры. Проверьте новые имена, форматы, примерные размеры или порядок документов в таблице.
3. Отметьте файлы, которые нужно обработать. При отсутствии отметок используются все подходящие видимые строки. Сводка под таблицей показывает состав пакета и количество скрытых файлов.
4. Запустите операцию. В итоговой сводке можно открыть готовый файл или папку, посмотреть подробности и повторить обработку файлов с временной ошибкой.

| Операция | Возможности |
| --- | --- |
| Переименование | Нумерация, даты, изменение регистра, добавление, удаление и замена текста, предпросмотр конфликтов и откат за текущую сессию. |
| Конвертация | Документы и изображения в доступные для исходного формата цели. Для проверки сложной вёрстки можно экспортировать один DOCX в PDF. |
| Объединение | Несколько PDF или несколько DOCX в заданном порядке. Порядок можно менять мышью или клавишами `Alt+↑` и `Alt+↓`. |
| Сжатие | PDF и изображения, копии или подтверждённая замена исходников, исходные и итоговые размеры файлов. |

Подробнее о форматах, фильтрах, отмене и настройках читайте в [руководстве пользователя](docs/USAGE.md).

## Разработка

Проект проверяется в Windows x64 на Python 3.15. Из корня клонированного репозитория выполните в PowerShell:

```powershell
py -3.15 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe multifora_start.py
```

Запуск проверок:

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
```

| Путь | Назначение |
| --- | --- |
| [`app/ui/`](app/ui/) | Окно, очередь, параметры операций, прогресс и результаты. |
| [`app/workers/`](app/workers/) | Фоновые обработчики Qt и фабрика рабочих потоков. |
| [`core/`](core/) | Модели, контракты, файловые операции и движки документов и PDF. |
| [`scripts/`](scripts/) | Сборка Windows, упаковка и проверки. |
| [`tests/`](tests/) | Тесты интерфейса, операций и сборки. |
