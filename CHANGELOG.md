# История изменений

## Следующая версия

- Автоматические тесты и сборка релизов через GitHub Actions.
- Архив Windows сопровождается контрольной суммой SHA-256 и автоматически сформированным списком изменений.
- Переименование по регулярным выражениям и преобразование регистра.
- Токены дат файла и EXIF для пользовательских шаблонов.
- Проверка конфликтов имён до запуска операции.
- Сохранение параметров операций в профили.
