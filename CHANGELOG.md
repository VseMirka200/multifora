# Журнал изменений

Все заметные изменения проекта фиксируются в GitHub Releases. Формат записей: добавлено, изменено, исправлено и безопасность.

## [1.0.3] — в разработке

Версия в исходном коде — `1.0.3`. Эта запись описывает подготовленные изменения и не подтверждает публикацию релиза.

### Добавлено

- На вкладке сжатия вместо типа файла показаны текущий и приблизительный размер после сжатия; оценка обновляется при изменении параметров.
- На вкладке конвертации показаны исходный и целевой формат каждого обрабатываемого файла, например DOCX → PDF.
- Отметки файлов в колонке «В работу», массовая установка и снятие отметок общим флажком в заголовке.
- Общая отрисовка флажков в таблице, фильтрах, настройках, меню и диалогах с поддержкой светлой и тёмной тем.
- Обновлённая светлая тема: обычное начертание основного текста, мягкий фон, тонкие разделители и более читаемые отключённые кнопки.
- Основные документы репозитория в корне; сайт и меню приложения ведут на Markdown-документы в GitHub.

### Изменено

- Интерфейс, сигналы фоновых обработчиков и IPC переведены на PySide6. Обновлены зависимости, запуск из BAT, тесты и конфигурация Windows-сборки.
- Удалён неиспользуемый слой сервисов и диспетчера операций. Оформление диалогов, определение темы и блокировка сигналов объединены в общие функции; стиль заставки перенесён в общий модуль стилей.

### Исправлено

- Зависимости Windows-сборки закреплены вместе с транзитивными пакетами. Сборка выполняется в отдельном окружении Python 3.11 x64; перед выпуском автоматически проверяются запуск EXE, работа с PDF, объединение DOCX и запуск Ghostscript.
- Проверка Windows-сборки больше не требует отсутствующий в новых версиях PyMuPDF файл; скрипт сборки использует Python из PATH, в том числе версию, настроенную в GitHub Actions.
- Переименование запускается отдельным лёгким обработчиком без загрузки библиотек конвертации и сжатия; он используется также для повторов и отката из истории.
- Операции учитывают отмеченные файлы и фильтры, а отметки сохраняются при переключении вкладок.
- Пустая таблица после удаления файлов подстраивается под панель и не сохраняет лишнюю прокрутку от длинных имён.
- Выбор файлов использует Qt-диалог без системного предпросмотра документов; чтение метаданных изображений явно закрывает исходный поток даже при ошибке и не открывает документы как изображения.
- Обработка ориентации фотографий, прозрачности и изображений QOI; сохранение страниц PDF в изображения и многостраничных изображений в PDF.
